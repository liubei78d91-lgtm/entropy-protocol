# 逆熵协议：三十日交易所

> 三十天，一座交易所，用记忆、健康与信用，向世界预支时间。

一个**单机文字策略游戏**：每天 3 点行动点，交熵税、打工、投资、典当记忆，收集能改写规则的碎片。
第三十天，账要清。**13 个结局，触发条件不公开。**

## 玩

在线玩：<https://你的用户名.github.io/entropy-protocol/> ← 部署后改成自己的链接

或者下载 `index.html` 相关文件到本地，直接双击（无需联网、无需安装）。

## 特点

- 30 天 / 每局约 5~8 分钟，适合反复刷结局
- 13 个隐藏结局：规则公开，结局条件不公开
- 10 段剧情、每段 3 个分支，选择会改变结局
- 纯静态单机：不联网、不收集任何数据，存档存在本机浏览器
- 手机、电脑都能玩，无任何依赖

## 玩法一句话

熵税每天涨，钱越多税越重；健康、记忆、熵值三条命，任何一条归零就结束；
规则碎片能改写骰子和规则，但每多一枚，每天就多啃掉一点记忆。
